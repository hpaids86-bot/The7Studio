## ✨ About The7Studio

**The7Studio** is a modern photography and cinematography studio website designed to showcase creative work, photography services, cinematic storytelling, and event coverage.

The website focuses on a **luxury, modern, emotional, and cinematic** visual experience while making it easy for customers to explore services, view the portfolio, and get in touch with the studio.

🌐 **Live Website:**
https://the7studio.pages.dev/

---

## 🎯 Project Objectives

* Showcase The7Studio's photography and cinematography services
* Present a premium and cinematic brand identity
* Display photography and creative portfolios
* Make it easy for customers to explore services
* Provide a clear path for customers to contact/book the studio
* Create a responsive experience across desktop, tablet, and mobile devices

## ⚙️ Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/The7Studio.git
```

### 2. Open the project

```bash
cd The7Studio
```

### 3. Run the website

Because this is a frontend website, you can open:

```text
index.html
```

directly in your browser.

For a better development experience, use **VS Code + Live Server**.
